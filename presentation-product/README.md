# Презентация продукта Social1

Одиннадцать слайдов 16:9 (1280×720) о платформе как о продукте: задача, карта
платформы, по слайду на каждый из пяти компонентов, сквозной сценарий, где все
пять работают на одном примере, общее основание и итог.

Отличается от `../presentation` — та собрана для руководства ДТСЗН и построена
вокруг логики пошагового отбора инициатив.

## Файлы

| Файл | Что это |
|---|---|
| `Main.dc.html`, `S02…S11.dc.html` | Слайды дизайн-канвы |
| `canvas.json` | Раскладка слайдов на полотне |
| `_style.frag`, `b*.frag`, `build.sh` | Общая шапка, тела слайдов и сборщик |
| `social1-prezentaciya-produkta.html` | Собранная канва |

## Правка

Слайды правятся в опубликованной канве или в исходниках. Во втором случае —
`b*.frag`, затем пересборка:

```bash
./build.sh
```

Шапка со шрифтами и общими стилями лежит в `_style.frag` и подставляется в каждый
слайд: правка стиля в одном месте расходится по всем одиннадцати.

## Шрифты

PT Serif (заголовки), PT Sans (текст) и PT Mono (надзаголовки, цифры) — те же, что
в выгрузке схем процессов. Цвета взяты из дизайн-системы портала (`web/css/app.css`).
