# Презентация Social1 для руководства ДТСЗН

Два формата одной презентации, 15 слайдов 16:9.

Ядро презентации — слайды 4–9: как именно работает пошаговый отбор инициатив.
Воронка и цена отказа на каждом этапе, устройство ворот, критерии и доказательная
база каждых ворот, маршруты четырёх решений, правила честности отбора.

## Файлы

| Файл | Что это |
|---|---|
| `Social1-prezentaciya-rukovodstvu-DTSZN.pptx` | Готовая презентация PowerPoint с заметками докладчика |
| `social1-prezentaciya-rukovodstvu.html` | Дизайн-канва: все 12 слайдов на одном полотне |
| `Main.dc.html`, `S02…S15.dc.html` | Исходники слайдов канвы |
| `canvas.json` | Раскладка слайдов на полотне |
| `build-pptx.cjs` | Сборщик файла PowerPoint |

## Пересборка PPTX

```bash
npm install pptxgenjs && node build-pptx.cjs
```

Скрипт вынесен из основного проекта: портал Social1 намеренно работает без
npm-зависимостей, и `pptxgenjs` нужен только для сборки презентации.

## Шрифты

В канве — PT Serif и PT Sans (те же, что в выгрузке схем процессов).
В PowerPoint — Cambria и Calibri: они входят в поставку Office и поддерживают
кириллицу, поэтому файл откроется одинаково на любом рабочем месте.
Если на компьютерах Департамента установлено семейство PT, замените названия
шрифтов в `build-pptx.cjs` (константа `F`) и пересоберите.
